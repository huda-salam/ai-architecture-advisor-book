# AI Technology & Architecture Advisor

A technical advisory field manual for the role of **Special Assistant to Regional Director — AI Technology & Architecture Advisor**.

The handbook focuses on independent technical judgment across AI/LLM, data, cloud, security, integration, architecture, reliability, scalability and technical economics.

## Principles

- Architecture before product.
- Evidence over assertion.
- Challenge assumptions, not people.
- Prefer simplicity when it satisfies the requirement.
- Preserve reversibility where practical.
- AI recommends; authorized humans decide.
- Distinguish facts, assumptions, inference and recommendation.
- A second opinion or dissenting opinion is a legitimate advisory output.
