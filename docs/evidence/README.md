# Evidence and Review

This directory contains the evidence, source reviews, and adversarial reviews supporting the book's chapters.

The main narrative remains under `docs/chapters/`. Evidence files are kept separately so that research and validation material does not appear as primary book chapters in site navigation.

## Structure

- Chapter-specific evidence and review files
- Cross-chapter adversarial reviews
- Final evidence and editorial audits

Evidence documents are supporting material for the book, not standalone chapters.
